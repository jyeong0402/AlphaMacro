yfinance 정보


맞습니다. `yfinance` 객체의 `news` 속성을 사용하면 특정 종목의 최신 금융 뉴스를 별도의 API 키 없이 무료로 쉽게 가져올 수 있습니다.

```python
import yfinance as yf

ticker = yf.Ticker("NVDA")
news_data = ticker.news

for article in news_data:
    print(f"제목: {article['title']}")
    print(f"출처: {article['publisher']}")
    print(f"링크: {article['link']}")

```

**`yfinance` 뉴스 기능의 한계 (NewsAPI 등 전문 API가 필요한 이유)**

현재 기획 중인 AlphaMacro는 금융 뉴스를 수집하여 긍정/부정 스코어링을 진행하고, 이를 과거 시뮬레이션(백테스트)에 활용하는 지능형 시스템입니다. 이 목적에 맞춰 `yfinance` 뉴스를 사용할 때 다음과 같은 기술적 한계가 존재합니다.

* **과거 시계열 조회 불가:** API 호출 시점 기준의 최신 뉴스(보통 8~10개 내외)만 반환합니다. 과거 특정 날짜 구간을 지정해 뉴스를 불러오는 기능이 없어, 과거 백테스팅용 데이터셋을 구축하는 것이 사실상 불가능합니다.
* **본문 텍스트 부족:** 뉴스 전체 본문이 아니라 짧은 요약(snippet)과 원문 링크만 제공하는 경우가 많아, FinBERT에 넣어 정교한 문맥 기반 감성 분석을 하기에는 입력 데이터의 품질이나 길이가 부족할 수 있습니다.

**💡 추천하는 개발 방향**

개발 초기 단계에서 **'오늘의 실시간 감성 분석'** 기능만 가볍게 구현해 보는 MVP 형태라면 `yfinance`를 사용하는 것이 가장 빠르고 효율적입니다. 이후 시스템이 고도화되어 과거 데이터 기반의 시그널 검증(백테스트)이 본격적으로 필요해지는 시점에 NewsAPI와 같은 외부 뉴스 전용 API로 전환하는 구조를 추천합니다.
