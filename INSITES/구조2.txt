[구조] AlphaMacro


AlphaMacro의 요구사항을 반영하여, 유지보수와 확장이 용이하도록 모듈화된 FastAPI 프로젝트 구조를 작성했습니다.

### 1. `models.py` (데이터베이스 ORM 모델)

PostgreSQL 데이터베이스 테이블과 1:1 매핑되는 SQLAlchemy 모델입니다.

```python
from sqlalchemy import Column, Integer, String, Float, Date, DateTime, ForeignKey, UniqueConstraint
from sqlalchemy.orm import declarative_base, relationship
from datetime import datetime
import uuid

Base = declarative_base()

class User(Base):
    __tablename__ = "users"
    
    user_id = Column(String, primary_key=True, default=lambda: str(uuid.uuid4()))
    email = Column(String(255), unique=True, index=True, nullable=False)
    password_hash = Column(String(255), nullable=False)
    created_at = Column(DateTime, default=datetime.utcnow)
    
    backtests = relationship("BacktestRecord", back_populates="user")

class MacroIndicator(Base):
    __tablename__ = "macro_indicators"
    
    indicator_id = Column(Integer, primary_key=True, autoincrement=True)
    symbol = Column(String(20), index=True, nullable=False) # US10Y, VIX 등
    date = Column(Date, nullable=False)
    value = Column(Float, nullable=False)
    
    __table_args__ = (UniqueConstraint('symbol', 'date', name='uq_macro_symbol_date'),)

class StockPrice(Base):
    __tablename__ = "stock_prices"
    
    ticker = Column(String(10), primary_key=True)
    date = Column(Date, primary_key=True)
    close_price = Column(Float, nullable=False)
    rsi_14 = Column(Float, nullable=True)
    macd = Column(Float, nullable=True)

class BacktestRecord(Base):
    __tablename__ = "backtest_records"
    
    backtest_id = Column(String, primary_key=True, default=lambda: str(uuid.uuid4()))
    user_id = Column(String, ForeignKey("users.user_id"), nullable=False)
    strategy_name = Column(String(100), nullable=False)
    cagr = Column(Float, nullable=True)
    mdd = Column(Float, nullable=True)
    sharpe_ratio = Column(Float, nullable=True)
    created_at = Column(DateTime, default=datetime.utcnow)
    
    user = relationship("User", back_populates="backtests")

```

from pydantic import BaseModel, Field
from typing import List, Optional
from datetime import date

# 매크로 관련 스키마
class CorrelationResponse(BaseModel):
    ticker: str
    indicator: str
    period: str
    correlation_coefficient: float

    start_date: date

    initial_capital: float = Field(..., gt=0)
    buy_conditions: str
    sell_conditions: str

class BacktestRunResponse(BaseModel):

    cagr: float
    mdd: float
    sharpe_ratio: float

## 2. AI 추론 엔진 모듈 (`services/ai_engine.py`)

Hugging Face의 `ProsusAI/finbert` 모델을 로컬 디바이스(CPU/GPU/MPS)에 적재하고, 텍스트 입력 시 `[-1.0, 1.0]` 사이의 감성 점수를 반환하는 클래스입니다.

```python
import torch
import torch.nn.functional as F
from transformers import AutoTokenizer, AutoModelForSequenceClassification

class FinBERTAnalyzer:
    def __init__(self):
        self.model_name = "ProsusAI/finbert"
        # 환경에 맞는 디바이스 자동 할당 (GPU, Apple Silicon MPS, 또는 CPU)
        if torch.cuda.is_available():
            self.device = torch.device("cuda")
        elif torch.backends.mps.is_available():
            self.device = torch.device("mps")
        else:
            self.device = torch.device("cpu")
            
        self.tokenizer = None
        self.model = None

    def load_model(self):
        \"\"\"서버 구동 시 모델을 메모리에 로드합니다.\"\"\"
        print(f"Loading {self.model_name} on {self.device}...")
        self.tokenizer = AutoTokenizer.from_pretrained(self.model_name)
        self.model = AutoModelForSequenceClassification.from_pretrained(self.model_name)
        self.model.to(self.device)
        self.model.eval() # 추론 모드로 전환
        print("FinBERT Model loaded successfully.")

    def analyze_sentiment(self, text_list: list[str]) -> float:
        \"\"\"
        텍스트 리스트를 입력받아 평균 감성 점수를 계산합니다.
        점수 범위: -1.0 (매우 부정) ~ 1.0 (매우 긍정)
        \"\"\"
        if not text_list:
            return 0.0

        # 토큰화 (패딩 및 잘라내기 적용)
        inputs = self.tokenizer(
            text_list, 
            padding=True, 
            truncation=True, 
            max_length=512, 
            return_tensors="pt"
        ).to(self.device)

        with torch.no_grad():
            outputs = self.model(**inputs)
            logits = outputs.logits
            probs = F.softmax(logits, dim=1)
            
        # ProsusAI/finbert 라벨: 0: positive, 1: negative, 2: neutral
        # 점수 계산 = 긍정 확률(%) - 부정 확률(%)
        pos_probs = probs[:, 0]
        neg_probs = probs[:, 1]
        
        # 각 문장의 감성 점수 계산 후 전체 평균 도출
        scores = pos_probs - neg_probs
        avg_score = scores.mean().item()
        
        return round(avg_score, 4)

# 싱글톤 인스턴스 생성
sentiment_analyzer = FinBERTAnalyzer()

```

## 3. 앱 라이프사이클 관리 (`main.py`)

FastAPI의 `@asynccontextmanager`를 사용하여 서버가 켜질 때 단 한 번만 무거운 PyTorch 모델을 로드하도록 구성합니다.

```python
from contextlib import asynccontextmanager
from fastapi import FastAPI
from routers import macro
from services.ai_engine import sentiment_analyzer

@asynccontextmanager
async def lifespan(app: FastAPI):
    # Startup: AI 모델 로컬 메모리에 로드
    sentiment_analyzer.load_model()
    yield
    # Shutdown: 필요시 메모리 해제 로직 추가
    print("Shutting down AI Engine...")

app = FastAPI(
    title="AlphaMacro",
    lifespan=lifespan
)

# 라우터 등록
app.include_router(macro.router)

```

## 4. API 라우터 연동 (`routers/macro.py`)

실제 API 요청이 들어왔을 때 크롤링된 뉴스(임시 데이터)를 추론 엔진에 전달하여 결과를 반환합니다.

요청하신 FastAPI와 FinBERT 연동 파이프라인 마크다운 문서가 준비되었습니다.


이번 파이프라인의 핵심은 **서버 리소스 최적화**와 **비동기 처리**입니다.

1. **Lifespan 이벤트 활용:** 과거 방식인 `on_event("startup")` 대신, FastAPI의 최신 규격인 `@asynccontextmanager`를 사용하여 서버가 시작될 때 무거운 PyTorch 모델을 메모리에 단 한 번만 적재하도록 설계했습니다. 이를 통해 매 API 호출마다 발생하는 모델 로딩 지연을 완전히 제거했습니다.
2. **비동기 논블로킹 (Non-blocking):** `asyncio.to_thread`를 사용하여 PyTorch의 텐서 연산(CPU/GPU 바운드 작업)이 FastAPI의 메인 비동기 이벤트 루프를 멈추지 않도록 분리했습니다.
3. **디바이스 자동 할당:** 로컬 환경에서 테스트하실 때 성능을 최대한 끌어낼 수 있도록 CUDA(GPU)나 Mac의 MPS, 혹은 CPU를 자동으로 감지하여 텐서를 할당하는 로직을 포함했습니다.

추가적으로 구현된 코드에서 크롤링 모듈을 덧붙이거나 백테스팅 데이터 파이프라인을 연결하고 싶으시다면 언제든 말씀해 주세요.
