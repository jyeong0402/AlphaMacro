# AlphaMacro
[개발 명세서] AlphaMacro  프로젝트명: AlphaMacro  개요: 거시경제(Macro) 지표와 주식 간 상관관계 분석, 뉴스·공시 감성 분석, 백테스팅을 단일 플랫폼에서 제공하는 지능형 주식 분석 시스템  타겟 사용자: 거시경제 흐름을 반영하여 체계적인 분할 매수·매도 전략을 수립하는 개인 및 전문 투자자  주요 기능 및 구성: 사용자 인증, 투자 성향 온보딩, 개인화 대시보드, 매크로 지표 분석, 종목 상관관계 분석, 뉴스·공시 감성 분석, 사용자 조건 백테스트, 거래일지, 실시간/지연 알림, Web/Mobile 클라이언트 지원
